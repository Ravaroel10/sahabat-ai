# Inline Elements - Visual Example

## Complete Example with All Three Element Types

### User Message:
> "Saya buruh bangunan dengan 3 anak sekolah, penghasilan Rp 1,5 juta per bulan"

---

### LLM Response (What It Writes):

```
Berdasarkan situasi Anda sebagai buruh bangunan dengan 3 anak sekolah dan penghasilan Rp 1,5 juta per bulan, saya rekomendasikan 2 program utama:

## 1. Program Keluarga Harapan (PKH)

[PROGRAM:pkh]

Program ini sangat cocok karena Anda memiliki 3 anak usia sekolah. PKH memberikan bantuan tunai bulanan dengan komponen untuk setiap anak, total bisa mencapai Rp 1-3 juta per tahun.

## 2. Kartu Indonesia Pintar (KIP)

[PROGRAM:kip]

Setiap anak Anda bisa mendapatkan KIP untuk biaya pendidikan. Besaran: SD Rp 450rb, SMP Rp 750rb, SMA/SMK Rp 1 juta per tahun per anak.

---

## Langkah Selanjutnya:

1. **Daftar ke Kelurahan** - Pastikan keluarga terdaftar di DTKS
2. **Hubungi Sekolah** - Tanyakan KIP untuk 3 anak
3. **Siapkan Dokumen** - KTP, KK, Surat Keterangan Penghasilan

Untuk melihat semua program lainnya yang sesuai:

[ACTION:marketplace]

Jika Anda memerlukan bantuan membuat dokumen pendukung seperti SKTM:

[ACTION:auto-birokrasi]

Semoga informasi ini membantu! 🙏
```

## Element Breakdown

### 1. Regular Text (Markdown)
```
Berdasarkan situasi Anda...
Program ini sangat cocok...
Langkah Selanjutnya:
```
- Rendered with proper markdown formatting
- Headings, bold, lists all work
- No code blocks or raw syntax

### 2. Inline Program Cards (2x)
```
[PROGRAM:pkh]  →  ┏━━━━━━━━━━━━━━━━━━┓
                   ┃ 💼 PKH Card      ┃
                   ┗━━━━━━━━━━━━━━━━━━┛

[PROGRAM:kip]  →  ┏━━━━━━━━━━━━━━━━━━┓
                   ┃ 💼 KIP Card      ┃
                   ┗━━━━━━━━━━━━━━━━━━┛
```
- Appear exactly where markers are placed
- Show program name, description, benefits
- "Lihat Detail" button links to detail page

### 3. Inline Action Buttons (2x)
```
[ACTION:marketplace]      →  ┌──────────────────────┐
                              │ 🛒 Marketplace       │
                              └──────────────────────┘

[ACTION:auto-birokrasi]   →  ┌──────────────────────┐
                              │ 📝 Auto-Birokrasi    │
                              └──────────────────────┘
```
- Appear exactly where markers are placed
- Full-width buttons with descriptions
- Link to respective features

### 4. Reference Cards (at end)
```
┌────────────────────────────┐
│ 💼 PKH [▼]                 │  ← Collapsible
│ ✓ Anda Memenuhi Syarat     │  ← Eligibility badge
└────────────────────────────┘

┌────────────────────────────┐
│ 💼 KIP [▼]                 │
│ ✓ Anda Memenuhi Syarat     │
└────────────────────────────┘
```
- Always at the end (from metadata)
- Expandable with full details
- "Lihat Detail" + "Ajukan Sekarang" buttons


### After (Dynamic Placement)
```
Text...
↓

↓
Text...
↓

↓
Text...
↓
Reference cards ← Summary
```

---

## Key Benefits

1. **Contextual Cards**: Appear where they're discussed, not after scrolling
2. **Visual Breaks**: Break up long text with interactive elements
3. **Better Flow**: Natural reading experience
4. **Multiple Types**: Programs + Actions in same response
5. **Dual Reference**: Inline (context) + End (summary)

---

## Summary

**Three inline element types work together:**
- 📝 **Text**: Markdown formatted content
- 💼 **Program Cards**: Inline with `[PROGRAM:id]`
- 🔘 **Action Buttons**: Inline with `[ACTION:type]`

**Plus reference cards at the end for complete summary!**

This creates a rich, interactive, and contextual chat experience. 🎯
